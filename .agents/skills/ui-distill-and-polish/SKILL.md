# UI Distill & Polish

## 1. Distill (Noise Reduction)
- **Eliminate Layout Shifts:** When state changes (e.g. switching tabs or options), preserve bounding dimensions to avoid jumpy content.
- **Context Clarity:** Group controls into clean segmented components instead of scattered individual buttons.
- **Clean States:** Active states must be immediately distinct through contrast, background, and crisp indicators.

## 2. Polish Pass
- **Zero Inconsistencies:** Verify that all interactive elements share the identical geometry rules (e.g., architectural square corners `border-radius: 0`).
- **Tactile Chips:** Selections should be visible as concise tags/chips with intuitive single-click removal (`×`).
- **Typography Alignment:** Align text baselines and optical weights for headers, labels, and numbers.
